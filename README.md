# HexBeat: Boxing Rhythm — site

Landing page, support and privacy policy for [HexBeat: Boxing Rhythm](https://apps.apple.com/app/id6827372551) on
Apple Vision Pro, served by GitHub Pages at https://oviniciusramosp.github.io/hexbeat-site/.

- `index.html` and `sitemap.xml` are generated: edit `build.py`, run `python3 build.py`, commit.
- `support.html` and `privacy.html` are written by hand. Keep the privacy policy true to the app (Health, hand
  tracking, ShazamKit, Game Center, the CloudKit shared boards).
- Images in `img/` come from the app's real captures and the App Store header art (see `build.py`).
